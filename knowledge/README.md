# Ailyre Design Knowledge

This directory is the public-ready, text-only knowledge layer of Site Collection. Patterns are authored summaries of design decisions and contracts. Agents should use them to implement fresh code in the user's stack.

- `patterns/`: normalized design patterns, anatomy, props, tokens, behavior, constraints and source references.
- `pattern.schema.json`: required structure for every pattern.
- `routes.csv`: one decision for every source item about inclusion and external routing.
- `ROUTING_AUDIT.md`: a human-readable decision for all 126 source items.
- `SOURCES.md`: consolidated credits for the authored patterns.
- `ATTRIBUTION_NOTICE.md`: public attribution text suitable for the API-key instructions page.
- `PUBLISHING.md`: the exact export boundary for a future public GitHub repository.
- `EVALUATION.md`: initial retrieval checks and known coverage gaps.

No screenshots, fonts, video, audio, copied components or provider responses belong here. Source repositories remain separate. A pattern's `source_refs` document provenance; they do not grant rights over assets outside the cited license scope.

The public API returns source credits with each pattern. Any copied source code is handled by the separate approved-file tool with its full license and notices. Third-party provider routes are connection suggestions for the user's own account, not server-side proxy calls.
